1. לכל הקורסים אותו מבנה, אותו סגנון ואותם רכיבים.
2. לכל קורס **צבע משלו**, כך שרואים מיד באיזה קורס נמצאים.
3. **מי שלא מתכנת יכול לערוך תוכן ולשנות סדר שיעורים** – ישירות באתר GitHub, בלי להתקין כלום ובלי לגעת בקוד.
4. הוספת קורס חדש = העתקת תיקייה ומילוי קבצי תוכן, בלי לכתוב קוד.

## 3. עקרונות (לא משנים בלי החלטה מפורשת)

1. **סטטי לגמרי.** אין שרת, אין מסד נתונים, אין התחברות. רץ על GitHub Pages כמו שהוא.
2. **בלי שלב build.** מה שנמצא בריפו הוא מה שמוצג. שמירה של קובץ באתר GitHub ← תוך דקה-שתיים האתר מתעדכן. (כך עובד היום קורס המיקרוביט, וזה עובד טוב.)
3. **תוכן בנפרד מקוד.** כל הטקסט נמצא בקובצי YAML עם הערות בעברית. עורך תוכן לא צריך לפתוח אף קובץ HTML/JS/CSS.
4. **מנוע אחד לכל הקורסים.** קוד ועיצוב משותפים בתיקייה אחת. קורס שונה רק בתוכן ובערכת הצבעים.
5. **עברית ו-RTL קודם.** שמות טכניים באנגלית (micro:bit, SPIKE) מוצגים בכיוון נכון.
6. **טעות בתוכן לא שוברת את האתר.** מזהה שגוי, שדה חסר או YAML שבור ← הודעת אזהרה ברורה בעברית באתר, שאר האתר ממשיך לעבוד.
7. **פשוט עדיף.** בלי פריימוורקים (React וכד׳). JS רגיל, CSS רגיל, ספרייה חיצונית אחת לקריאת YAML (`js-yaml`, גרסה נעולה, מ-cdnjs).

## 5. עיצוב: שפה אחת, צבע לכל קורס

### מה משותף לכל הקורסים
- מסגרת טכנודע: לוגו, פס הצבעים בכותרת, כותרת תחתונה.
- גופן **Rubik**, גדלים, ריווחים, פינות מעוגלות, צללים – מתוך `shared/style.css` (בסיס: העיצוב של קורס המיקרוביט).
- אותם רכיבים: כרטיס מפגש, כרטיס שיעור, תגיות, כפתורים, לשוניות, חיפוש, הודעות אזהרה.
- מצב כהה (dark mode) – לפי הגדרת המכשיר + כפתור החלפה (קיים היום ב-FLL, יתווסף לכולם).

### מה שונה בין קורסים: ערכת צבעים
כל קורס מגדיר ב-`course.yml` שדה `theme`. ערכת הצבעים משפיעה על: שם הקורס בכותרת, באנר הפתיחה, כפתורים ראשיים, קישורים, פס צבע בצד כרטיס המפגש, והאייקון בכרטיס בדף הבית.

| קורס | `theme` | צבע ראשי (הצעה) | הערה |
|---|---|---|---|
| מיקרוביט | `microbit` | סגול טכנודע `#7b4fa8` | כמו היום |
| FLL | `fll` | ירוק `#0f8a5f` | כמו היום (BIOGLOW) |
| לגו אתגרי | `lego` | כתום-אדום `#d9541e` | להחלטה |

- כל צבע מוגדר פעם אחת כמשתנה CSS (`--course`, `--course-ink`, `--course-tint`) ב-`shared/themes.css`, בגרסה בהירה ובגרסה כהה.
- ניגודיות טקסט מול רקע לפחות 4.5:1 (WCAG AA) בשני המצבים.
- צבעי "חלקים" בתוך קורס (למשל micro:bit מול Tiny:bit) הם צבעים משניים ולא מתנגשים עם הצבע הראשי של קורס אחר.

## 7. מודל התוכן (קובצי YAML)

כל קובץ מתחיל בבלוק הערות בעברית שמסביר את השדות (כמו היום ב-`schedule.yml` וב-`lessons.yml` של מיקרוביט).

### `courses.yml` (שורש הריפו)
```yaml
courses:
  - id: microbit           # שם התיקייה
    title: "מעבדת מיקרוביט"
    summary: "תכנות, אורות, צלילים ורובוטים"
    theme: microbit
    visible: true          # false = לא מופיע בדף הבית (קורס בהכנה)
  - id: fll
    title: "FIRST LEGO League"
    summary: "רובוטיקה, מחקר ועבודת צוות לקראת התחרות"
    theme: fll
    visible: true
```

### `<course>/course.yml`
```yaml
title: "מעבדת מיקרוביט"
theme: microbit
welcome: "28 מפגשים של תכנות, אורות, צלילים ורובוטים. מי אתם?"
footer: "השיעורים מבוססים על ..."   # אפשר קישורים בפורמט [טקסט](כתובת)
features:                  # מה מופעל בקורס הזה
  student_page: true
  guide_page: true
  search: true
  bank: true               # מאגר שיעורים נוסף
platform: makecode         # makecode / spike / ev3 / none – קובע אילו כפתורי קוד יוצגו
```

### `<course>/schedule.yml` – סדר המפגשים
נשאר בדיוק במבנה של היום במיקרוביט (`parts` + `sessions` עם `num`, `part`, `title`, `lessons`, `student_note`, `guide_note`).
תוספות אפשריות (לא חובה):
- `date:` תאריך המפגש (מוצג על הכרטיס, ומסמן "המפגש הבא").
- `page:` מזהה עמוד מיוחד שמקושר מהמפגש (למשל `first-lesson`).
- `hidden: true` – מפגש שלא מוצג לתלמידים עדיין.

### `<course>/lessons.yml` – מאגר השיעורים
המבנה של היום במיקרוביט (`id`, `title`, `source`, `level`, `concepts`, `summary`, `student`, `guide`, `images`, `links`).
- השדות `student` ו-`guide` משותפים לכל הקורסים.
- שדות ייחודיים לפלטפורמה נמצאים תחת `links` (למשל `makecode`/`hex` במיקרוביט; `spike` / קובץ `.llsp3` / הוראות בנייה PDF ב-FLL ולגו).
- שדה שהמנוע לא מכיר – מתעלמים ממנו בשקט (לא שובר).
- עיצוב בתוך טקסט: `**מודגש**`, `[[שם בלוק]]`, `[טקסט](קישור)`.

### `<course>/pages/<id>.yml` – עמוד מיוחד
```yaml
title: "דף מנחה – השיעור הראשון"
audience: guide            # guide / student / all
blocks:
  - type: hero
    tag: "עונת BIOGLOW 2026–2027"
    title: "השיעור הראשון"
    countdown: "2027-01-28T09:00"   # ספירה לאחור (לא חובה)
  - type: timer
    steps:
      - { minutes: 15, title: "סיור והיכרות" }
      - { minutes: 30, title: "בנייה בקבוצות" }
  - type: checklist
    id: prep               # מזהה לשמירת הסימונים במכשיר
    title: "הכנה לפני השיעור"
    items:
      - "רשימת שמות מודפסת + תגיות שם"
  - type: video
    youtube: "2J_yiy8yjHw"
    title: "סרטון העונה"
  - type: gallery
    images: [images/competition-1.jpg, images/competition-2.jpg]
  - type: text
    title: "..."
    body: |
      טקסט חופשי עם **הדגשה** ו[קישור](https://...)
  - type: links
    items:
      - { title: "אתר FIRST ישראל", url: "https://firstisrael.org.il/" }
```

## 8. רכיבי תוכן (בלוקים)

| בלוק | מה עושה | מקור |

## 9. עריכה ע"י מי שלא מתכנת

### תהליך עריכה רגיל
1. נכנסים לריפו ב-github.com ← לתיקיית הקורס ← לקובץ (`schedule.yml` / `lessons.yml` / `pages/...`).
2. לוחצים על העיפרון ✏️, עורכים, לוחצים **Commit changes**.
3. אחרי 1–2 דקות האתר מתעדכן. אם משהו לא תקין – באתר מופיעה הודעה כתומה שמסבירה מה ואיפה.

### מה המערכת עושה כדי שזה יהיה בטוח
- הערות בעברית בראש כל קובץ + דוגמה מוכנה להעתקה.
- **בדיקה אוטומטית ב-GitHub Actions** בכל שמירה: YAML תקין, אין מזהים כפולים, כל מזהה ב-`schedule.yml` קיים, קישורי תמונות קיימים. אם נכשל – מייל + ✗ אדום ליד השמירה, עם הסבר בעברית. (האתר עצמו לא תלוי בבדיקה הזו.)
- הודעות שגיאה באתר מציינות קובץ, מספר מפגש/מזהה שיעור, ומה לתקן.
- `docs/CONTENT-GUIDE.md`: "איך עושים..." – החלפת שיעור, הוספת שיעור, העלאת תמונה, הסתרת מפגש, הוספת קורס.
- **תצוגה מקדימה לפני פרסום (לא חובה):** מי שרוצה לבדוק שינוי גדול – עורך בענף (branch) נפרד, ורואים אותו בתצוגה מקדימה לפני מיזוג. (שלב מתקדם, M7.)

### מחוץ לתחום כרגע
ממשק עריכה גרפי (CMS כמו Decap/Netlify CMS) – דורש שרת התחברות, לא תואם "סטטי לגמרי". אפשר לבחון בעתיד.

## 10. דרישות כלליות

- **מובייל:** עובד ברוחב 360px בלי גלילה לרוחב. כפתורים לפחות 44px.
- **מקרן:** טקסט קריא ממרחק; מצב "הקרנה" לסרטונים ולטיימר.
- **הדפסה:** דף שיעור למדריך מודפס נקי (בלי כותרת/תפריט, בלי צבעי רקע).
- **נגישות:** WCAG 2.1 AA – ניגודיות, ניווט מקלדת, focus נראה, `alt` לתמונות, `lang="he" dir="rtl"`.
- **ביצועים:** עמוד נטען בפחות מ-2 שניות ברשת סלולרית; תמונות דחוסות (עד ~300KB), `loading="lazy"`.
- **ספריות חיצוניות:** רק מ-cdnjs, עם גרסה מדויקת.
- **פרטיות:** אין אנליטיקס, אין עוגיות. דפי מדריך אינם סודיים (כל מי שיודע את הכתובת נכנס) – לא מעלים מידע רגיש. **תמונות ילדים רק באישור הורים**, ובלי שמות מלאים.
- **תאימות:** Chrome / Edge / Safari בגרסאות מהשנתיים האחרונות.
